# 4ps

A fast and lightweight web tool designed to optimize MP4 videos for TikTok.

## Features

- **Smooth 60 FPS**: Preserves high frame rate playback when uploaded to TikTok without being capped or downgraded.
- **Lossless Quality**: Retains your video's original visual clarity and crisp details with zero re-encoding loss.
- **Fast & Private**: Fast processing with no server video storage—your video media stays on your device.
